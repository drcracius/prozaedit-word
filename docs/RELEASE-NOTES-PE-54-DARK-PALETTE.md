# PE-54 — Dark theme color revision

Dark mode now follows a **warm charcoal** neutral stack (in the spirit of VS Code **Dark+** editorial warmth): base `#1a1a1c` → pane `#212124` → cards `#2a2a2e`, with off-white primary text and softer violet-indigo accents instead of cold blue-slate and neon green.

**Light theme** and `[data-pe-theme="light"]` tokens are unchanged. See `docs/pe-ui-design-notes.md` for the dark palette table.
