## Install steps (bullet list for testers)

- **Requirements:** Microsoft account, Word on the web (https://office.com), internet while using the add-in.
- **Get manifest:** Save [manifest.hosted.xml (raw)](https://github.com/drcracius/prozaedit-word/raw/main/manifest.hosted.xml) to Downloads (or use the file attached to this invite).
- **Upload once:** New blank doc → Add-ins → More Add-ins → **Upload My Add-in** → pick the manifest.
- **Use daily:** Open your document → **Home → ProzaEdit** (no extra apps or `.bat` files).
- **Desktop Word:** Upload is often missing; use the browser steps above for install, then use Word desktop if you prefer after upload.
- **Updates:** UI refreshes from Pages after pushes to `main`; re-upload manifest only when the author announces a new `<Version>`.
