# PE-55 — Black dark theme, light green accents

User feedback after PE-54: dark backgrounds should read as **true black** (terminal / OLED / IDE style), and **purple-on-black** accents were replaced with **light green** for primary actions, links, tabs, workflow, and focus rings.

**Light theme** and `[data-pe-theme="light"]` tokens are unchanged. See `docs/pe-ui-design-notes.md` for the dark palette table.
