PROZAEDIT — BETA TESTER (one-time install)

You received manifest.hosted.xml from the ProzaEdit author.

REQUIREMENTS
  - Microsoft Word (desktop or word.office.com)
  - Internet while using ProzaEdit

STEPS (Word on the web — easiest)
  0. If ProzaEdit is already installed: My Add-ins → ... on ProzaEdit → Remove.
  1. Save manifest.hosted.xml from the author's raw link (not the GitHub web page):
     https://github.com/drcracius/prozaedit-word/raw/main/manifest.hosted.xml
  2. Go to https://office.com → Word → create a NEW blank document.
  3. Add-ins → More Add-ins → My Add-ins → Manage My Add-ins
  4. Click Upload (dropdown menu) → Upload My Add-in → pick manifest.hosted.xml
  5. Open your real manuscript (same account). Home → ProzaEdit

Note: Upload may fail on an old blank doc; use a fresh blank doc for step 2–4.
If Word says the manifest is not valid, ask for a fresh raw download (build 2.0.0.61+).
Desktop Word often has no Upload — use the browser steps above.

DAILY USE
  Open Word → Home → ProzaEdit
  (No extra apps or bat files from the author.)

If Upload is missing on desktop Word, use https://office.com in a browser for step 2–4.
