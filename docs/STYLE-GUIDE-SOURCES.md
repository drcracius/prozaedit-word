# Style guide pack sources

ProzaEdit **style guide** audit cards use short, original phrase lists in `src/taskpane/lib/style-guide-rules.js`. They are **not** copies of full style manuals.

| Pack id | Inspiration | License / notes |
|---------|-------------|-----------------|
| `plain-us` | U.S. Plain Language guidelines | [CC0](https://creativecommons.org/publicdomain/zero/1.0/) / public guidance |
| `strunk` | Strunk, *Elements of Style* (1920) | Public domain |
| `govuk` | GOV.UK style A–Z | [Open Government Licence v2.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/2/) |
| `microsoft` | Microsoft Writing Style Guide | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `google-dev` | Google Developer Documentation Style Guide | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `redhat` | Red Hat technical writing guidance | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |

Custom house rules are stored per document via the Target tab; they are your content only.

For APIs, macros, and other third-party relationships, see [THIRD-PARTY-ATTRIBUTION.md](THIRD-PARTY-ATTRIBUTION.md).

*Aligned with hosted build **2.0.0.15**.*
