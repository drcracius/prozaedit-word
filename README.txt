PROZAEDIT (hosted beta — daily use)

Word ON THE WEB (recommended for install):
  1. Download manifest.hosted.xml from GitHub (the only file Word should use):
     https://github.com/drcracius/prozaedit-word/raw/main/manifest.hosted.xml
     Or run Download-Manifest-From-GitHub.bat (saves to Downloads).
  2. Remove any old ProzaEdit: My Add-ins → ... → Remove.
  3. Add-ins → My Add-ins → Upload My Add-in → pick that downloaded file.

  Tip: Upload often works on a NEW blank document first, then open your real file.

Daily use: Home → ProzaEdit (no bat files).

Scope: Target tab → selection, page range, chapter(s), or full ms → Refresh count.
